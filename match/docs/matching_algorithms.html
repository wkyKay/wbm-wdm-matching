WBM-WDM 匹配算法文档

本文档说明 match.scripts.main 中涉及的 Proposal Mode（Token 提取策略）以及共用的 Match Score（匹配得分）计算方法。

一、Proposal Mode — Token 提取策略

Proposal Mode 决定了如何将 WBM / WDM 的缺陷分布图（grid map）切分为若干 Token（局部缺陷簇），供后续 Token 匹配使用。通过 --proposal-mode 指定，支持四种值：

模式CLI 值描述
Connected Components cc（默认） 对二值 mask 做 8-连通域标记，按面积和重要性排序取 top-K 个 Token。
Retrieval Compact compact 在 cc 基础上增加了边缘环形 Token 提取，适合具有外圈缺陷环的晶圆图案。
Sparse Density sparse-density 多尺度高斯核密度估计（KDE），将权重连续化后再提取连通域，适合稀疏、碎片化的缺陷分布。

1.1 cc — Connected Components

  1. 对输入的二值 mask 执行 8-连通域标记（connected components labeling）。
  2. 丢弃像素数 < min_area（默认 5）的连通域。
  3. 计算每个连通域的统计量：质心、PCA 主方向/特征值、包围盒、周长、面积。
  4. 按重要性排序：sqrt(mass) + 0.25×sqrt(area) + type_bonus，保留 top-K（默认 6）。
  5. 对每个 Token 计算 Zernike 矩（degree=8, 48×48 裁剪）+ 几何特征描述子。

1.2 compact — Retrieval Compact

  1. 先和 cc 一样去噪（丢弃小连通域）。
  2. 尝试提取 环形边缘 Token（ring band）：
    • 找径向距离 ≥ 0.65 的边缘像素，要求角向覆盖率高、径向标准差低。
    • 通过多重质量门控（最小面积、角向覆盖率、最大径向标准差、最大缺陷比、最小边缘缺陷占比）。
  3. 从 mask 中减去环区域，对残差部分再次提取 cc Token。
  4. 用 多样性选择策略 取 top-K：尽量覆盖 center / blob / line / irregular 四种几何类型 + ring Token。

1.3 sparse-density — 多尺度 KDE

  1. WDM 的权重图先经过变换（--density-weight-transform，默认 sqrt，可选 count / log1p）。
  2. 对每个 sigma（默认 [0.8, 1.6, 3.2]）执行：
    • 高斯核密度估计：手动卷积，不依赖 SciPy。
    • 以峰值密度的 --density-threshold（默认 0.20）为阈值截取 support mask。
    • 在 support mask 上找连通域，过滤掉 raw_points < 3 或 raw_mass < 3.0 的 Token。
  3. 跨尺度去重：IoU ≥ --density-merge-iou（默认 0.60）的 Token 视为重复，仅保留一个。
  4. 排序：sqrt(raw_mass) + 0.25×sqrt(area) + 0.05×peak_density，保留 top-K。

二、Match Score — Token 匹配得分

WBM 与 WDM 的 Token 之间计算 综合匹配得分，由四个子维度加权合成。最终得分用于贪心一对一匹配，并聚合为整张 Wafer Map 的整体匹配分数。

2.1 权重归一化

三个顶层权重先做归一化（默认值），确保总和为 1：

参数CLI 选项默认值
Shape 权重 w_shape--token-score-shape-weight0.60
Position 权重 w_position--token-score-position-weight0.25
Scale 权重 w_scale--token-score-scale-weight0.15

2.2 Shape Similarity — 形状相似度

形状相似度结合 Zernike 矩描述子和几何特征：

shape_sim = (0.75 × moment_sim + 0.25 × geometry_sim) / (0.75 + 0.25)
  • moment_sim：Zernike 矩描述子（degree=8）的余弦相似度，范围 [-1, 1]。
  • geometry_sim： exp(-mean_abs_diff / 0.25)，其中 mean_abs_diff 来自以下几何特征差值：
    • fill_ratio — 填充率
    • log1p(aspect_ratio) / log(16) — 宽高比（对数归一化）
    • log1p(elongation) / log(64) — 延伸度（对数归一化）
    • min(compactness / 4, 1) — 紧致度（截断）
    • angular_coverage — 角度覆盖度
    • radial_std — 径向标准差
Shape Similarity   ∈   [0, 1]
门控：若 shape_sim < 0.30，该 Token pair 直接被判为不匹配（score = 0），不参与后续匹配。这是硬性形状门槛。

2.2.1 Zernike 矩描述子详解

Zernike 矩是一组定义在单位圆上的正交多项式基函数的投影系数，具有旋转不变性（取模后）和信息紧凑性，非常适合描述 Token 的形状。本系统中使用的参数为：

参数值含义
ZERNIKE_DEGREE8最高阶数 n ≤ 8
ZERNIKE_CROP_SIZE48×48输入 mask 统一缩放到 48×48 像素
描述子维度20满足 n≤8, (n-m)%2=0, (n,m)≠(0,0) 的模值个数
归一化L2-norm = 1描述子向量除以自身 L2 范数

计算流程

  1. 构建裁剪 Mask：根据 Token 的像素坐标取出最小包围矩形，得到二值 mask。
  2. 居中 & 缩放：将 mask pad 为正方形（四周留 2px 边距），最近邻插值缩放到 48×48。
  3. 映射到单位圆：以图像中心为原点，最大半径为 1，计算每个像素的归一化极坐标 (ρ, θ)：
    x = (col - center) / radius,   y = (row - center) / radius
    ρ = √(x2 + y2),   θ = atan2(y, x)
    仅 ρ ≤ 1 的像素（单位圆内）参与计算。
  4. 计算 Zernike 矩：对每个满足条件的 (n, m) 对（n ≤ 8，(n-m) 为偶数，排除 (0,0)），计算复数矩：
    Anm = n+1M × ∑(x,y) ∈ disk f(x,y) · Rnm(ρ) · e-i·m·θ
    其中 M = ∑ f(x,y) 为 mask 总质量（用于面积归一化），f(x,y) 为 mask 值（0/1）。
  5. 取模：|Anm| 即为旋转不变的描述子分量，丢掉相位信息。
  6. L2 归一化：20 个模值组成描述子向量，除以向量自身的 L2 范数，使 ||desc|| = 1。

Zernike 径向多项式

径向多项式 Rnm(ρ) 的计算公式为：

Rnm(ρ) = ∑s=0(n-m)/2 (-1)s · (n - s)!s! · (n+m2 - s)! · (n-m2 - s)! · ρn-2s

2.3 Position Affinity — 位置亲和度

基于归一化坐标（[0,1] 范围的行/列）的高斯距离：

pos_affinity = exp( -|| pWBM - pWDM ||2 / σpos2 )

其中 σpos = 0.35（固定值）。

Position Affinity   ∈   (0, 1]

2.4 Scale Affinity — 尺度亲和度

尺度亲和度由两个子成分加权合成：

参数CLI 选项默认值
面积权重 w_area--token-scale-area-weight0.50
PCA 权重 w_pca--token-scale-pca-weight0.50
scale_affinity = w_area × area_aff + w_pca × pca_aff

2.4.1 Support Area Affinity

比较 Token 的支撑面积占整个 valid 区域的比例：

area_ratio = support_areatotal_valid_area
area_aff = exp( -| ln(ratioWBM / ratioWDM) | / σscale )

2.4.2 PCA Extent Affinity

比较 PCA 特征值所描述的形状延展尺度：

long_extent = √( max(λ1, 0) + 1 )
short_extent = √( max(λ2, 0) + 1 )
Δ = 0.75 × |ln(longWBM / longWDM)| + 0.25 × |ln(shortWBM / shortWDM)|
pca_aff = exp( -Δ / σscale )
其中 σscale 为固定值，long extension 权重 0.75、short extension 权重 0.25 均为硬编码。
Scale Affinity   ∈   (0, 1]

2.5 Type Affinity — 类型亲和度

当前硬编码为 1.0，不作为区分因子，仅在解释性输出中保留标签。

2.6 综合 Token 得分公式

score = wshape×Sshape + wpos×exp(-d2/σpos2) + wscale×( warea×Aarea + wpca×Apca )

其中：

  • 门控条件：Sshape ≥ 0.30，否则 score = 0
  • 最终过滤：score 必须 ≥ --token-min-score（默认 0.30）
  • 权重默认归一化后：w_shape=0.60, w_pos=0.25, w_scale=0.15
  • 尺度子权重：w_area=0.50, w_pca=0.50
Token Match Score   ∈   [0, 1]

三、贪心匹配与聚合得分

3.1 贪心一对一匹配

  1. 所有 Token pair 按 score 降序排列。
  2. 遍历排序列表：若该 pair 的 WBM Token 和 WDM Token 均未被占用，则建立匹配。
  3. 每个 Token 最多匹配一次（Hungarian-like greedy）。

3.2 Token 过滤

参与评分的 Token 须满足：token_area / max_token_area ≥ min_relative_token_area（默认 0.10）。过小的 Token 被排除。

3.3 加权聚合得分

每个 WBM Token i 权重为其面积的平方根：

weighti = √( max(areai, 1) )

加权平均：

overall_score = ∑ scorei × weighti∑ weighti

未匹配的 WBM Token 贡献为 0。各子维度均值（mean_shape、mean_position、mean_scale）同样按权重平均。

3.4 两种输出变体

输出指标分母含义
count-partial 所有通过过滤的 WBM Token 全量加权得分（未匹配 = 0）
count-partial-mo 仅实际匹配的 WBM Token Matched-Only 得分，仅考虑找到匹配的 Token
